# Gioielleria Meda — sito

Home page in un unico file: `index.html` (HTML + CSS + JS incorporati, nessun framework).
Aprirlo direttamente nel browser per l'anteprima.

## Prima di pubblicare

Tutti i segnaposto sono elencati nel commento in cima a `index.html`. In breve (Cerca e sostituisci):

| Cosa | Segnaposto |
|---|---|
| Numero WhatsApp | `390000000000` |
| Telefono (link / visibile) | `+390171000000` / `0171 000000` |
| Orari | tabella in `#contatti` + JSON-LD nell'`<head>` |
| Social | commento `SOCIAL:` nel footer |
| Testi storia | commenti `SEGNAPOSTO TESTO` |
| Foto | commenti `FOTO:` (tag `<img>` già pronti, WebP, dimensioni indicate) |
| P.IVA | footer |

Togliere `<meta name="robots" content="noindex, nofollow">` alla messa online e ospitare i font in locale (GDPR).
